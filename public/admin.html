4. Put the changes on chain

This changes your NFTs for real and costs a small network fee. Start with the test. Each changed NFT gets a new metadata file (stored on Arweave through Irys, about 0.000004 SOL per file) and one update that points it to the new file. Your wallet first sends a small SOL amount to a temporary upload key that exists only in this tab; the leftover comes back at the end.
